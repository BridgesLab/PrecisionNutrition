MR mediation: exposure → mediator → AD

Direct and indirect effects via two-step MR and MVMR, with survival-collider adjustment carried through every leg

Author

Dave Bridges and Katie Kittell

Published

October 8, 2026

Purpose

Steps 1–2 estimated each exposure’s total effect on AD and corrected it for the survival collider. This step asks how much of a total effect runs through a named mediator. The motivating triad is

\[\text{lean mass} \;\to\; \text{2-h glucose} \;\to\; \text{AD},\]

with the hypothesis that part of lean mass’s protective effect on AD comes from lower postprandial glucose. The code is written for any number of triads, including exposure → tissue expression → AD (see eQTL mediators).

Primary estimands: the indirect effect (product of coefficients, \(\beta_{X\to M}\times\beta_{M\to Y\mid X}\)) and the direct effect (\(\beta_{X\to Y\mid M}\) from MVMR), each with a Monte Carlo CI. Percent mediated is secondary and is reported only for triads that pass the pre-specified gates. Methods follow Carter et al. 2021 (Eur J Epidemiol, PMID 33961203); conditional F and Q follow Sanderson, Spiller & Bowden 2021 (Stat Med 40:5434–52, doi:10.1002/sim.9133, PMID 34338327).

Warning

The motivating triad’s exposure and mediator GWAS both fail the spec’s covariate requirements. The spec asks for lean mass with no fat-mass/BMI/height adjustment and a BMI-unadjusted 2hGlu. The IDs used by the existing pipeline are:

  • ebi-a-GCST90000025: fat-mass-adjusted appendicular lean mass (Pei 2020).
  • ebi-a-GCST90002227: BMI-adjusted 2hGlu. Chen 2021 adjusted FG, FI and 2hGlu for BMI, and the GWAS Catalog lists no unadjusted European 2hGlu from that paper (GCST90002225–29 are the per-ancestry and trans-ancestry versions of the same adjusted analysis).

Both adjustments condition on adiposity, which lean mass and glucose each affect. So the X → M leg, and the M | X coefficient, can carry collider bias in either direction. Pei 2020 reports that its adjusted ALM has its strongest negative genetic correlation with BMI-adjusted 2hGlu, which is the exact pair used here. The notebook runs as specified, but every lean-mass triad is labelled COLLIDER RISK until unadjusted replacements are supplied.

A second data note: the 2hGlu file’s beta/standard_error are from the raw-trait (mmol/L) model, but its p_value is from the inverse-normalised model (Catalog README.txt). Instruments are therefore selected on a p-value that does not come from the reported beta. Both legs that use M are still on the same mmol/L scale, so the indirect effect’s units are internally consistent. The p-value cross-check quantifies the mismatch.

Triads

One row per triad × outcome. method_XY_total is copied from Step 2’s validated naive_model. method_XM was not covered by the prior assumption checks (lean mass → 2hGlu was never run as a univariable association), so it is provisional: the X → M checks below exist to confirm or replace it. method_MVMR is the pre-specified multivariable analog of the leg methods: ivw_mre → mv_ivw_mre, mr_presso → mv_presso, mr_raps → grapple.

)

# The 2 x 2 sensitivity grid: every triad x outcome under both adjustment states.
ADJUSTMENTS <- c("slopehunter", "none")

# Overrides the pre-specification check below. Leave FALSE: the equivalence bound exists to be

ALLOW_UNSET_EQUIV_BOUND <- FALSE

common_snp_set = TRUE means the raw arm also drops SNPs that have no lifespan association. Raw and SlopeHunter-adjusted estimates then share an identical SNP set, so the difference between them reflects the adjustment alone and not a change in instruments. With FALSE, the raw arm reproduces the prior univariable instrument set exactly.

Instruments

Selection reuses the prior univariable pipeline exactly: p < 5×10⁻⁸, clumping at r² < 0.001 within 10 Mb on the OpenGWAS 1000G-EUR LD server, harmonisation action = 2 (palindromes inferred from allele frequency, ambiguous ones dropped), LD proxies at r² ≥ 0.8 (TwoSampleMR defaults), and no F-statistic filter. The relaxed drug-target criteria (smoking/config.yml: cis_drugtarget) are not used. Any per-triad change goes through inst_override and is written to the deviation log.

The MVMR instrument set is the union of X and M instruments, re-clumped with the same parameters and extracted for both traits (TwoSampleMR::mv_extract_exposures).

pull_triad <- function(triad_id, exposure_id, mediator_id, rp) {
  x <- exposure_id; m <- mediator_id; par <- rp$par
  # Fail on the first pull that returns nothing, naming the call and the server's reason.
  need <- function(val, what) {
    if (is.null(val)) stop("OpenGWAS pull failed for ", triad_id, ": ", what, " -> ",
                           og_last_error(), ". A 5xx code is a server outage (retry later); ",
                           "401/403 is the token (check ieugwasr::user()).", call. = FALSE)
    val
  }
  x_inst <- need(pull_instruments(x, par, CACHE_DIR), paste("instruments for", x))
  m_inst <- need(pull_instruments(m, par, CACHE_DIR), paste("instruments for", m))
  mv_exp <- need(pull_mv_exposures(x, m, par, CACHE_DIR), "mv_extract_exposures (re-clump X u M)")
  list(x_id = x, m_id = m, x_inst = x_inst, m_inst = m_inst, mv_exp = mv_exp,
       x_in_m = pull_snps(x_inst$SNP, m, par, CACHE_DIR),
       m_in_x = pull_snps(m_inst$SNP, x, par, CACHE_DIR))
}

Outcome tables (built once per outcome)

For each AD outcome, the outcome effects and the parental-lifespan effects are extracted once for the union of every triad’s instruments, with lifespan aligned to the outcome’s effect allele. Every triad then reads from that one table, which makes the “never mix adjusted and unadjusted data within a triad” rule hold by construction.

Note

Sign convention (from Step 2): the lifespan axis GCST006697 is a Martingale residual that increases with mortality. b_SH was fit on the same axis, so the SNP-level adjustment \(\beta^{adj}_Y = \beta_Y - b_{SH}\,\beta_{life}\) is internally consistent. Do not negate either term.

# Same logic as Step 2's load_bsh(): the fitted value is always shown, but it is applied only
# when trusted.
load_bsh <- function(ad_id) {
  src <- bsh_sources |> filter(ad_id == !!ad_id)
  na_row <- tibble(ad_id = ad_id, b_SH = NA_real_, se_SH = NA_real_, trusted = FALSE,
                   reason = "no fits CSV", boot = list(NULL))
  if (nrow(src) == 0 || !file.exists(src$fits_csv[1])) return(na_row)

Estimation

Per arm (triad × outcome × adjustment):

  1. Total: univariable X → Y on X’s own instruments, using method_XY_total.
  2. X → M: univariable on X’s own instruments in the mediator GWAS, using method_XM.
  3. MVMR: X and M jointly on Y, using the re-clumped union and method_MVMR. This gives direct = β(X → Y | M) and β(M → Y | X) with their joint covariance.
  4. Indirect = β(X → M) × β(M → Y | X). Both glucose coefficients come from the same 2hGlu GWAS, so the mediator’s units cancel and the indirect effect is in log-OR per unit X.
  5. Consistency: (direct + indirect) − total, in units of the total’s SE.

Uncertainty (Monte Carlo). The four legs are drawn jointly from a multivariate normal. The MVMR block uses the method’s own covariance. Correlations between the other legs come from a SNP-level parametric bootstrap, because total, X → M and MVMR share SNPs and GWAS, and total and direct share the outcome. For adjusted arms, b_SH is also redrawn. The legs are refit on a grid of b_SH values (re-adjusting the outcome at every grid point), and each draw interpolates the estimates and covariance at its own b_SH. This carries the shared-slope correlation between adjusted SNP effects, which naive IVW SEs omit. MR-PRESSO outlier sets are found once at the point estimate and held fixed across the grid. Delta-method SEs for the indirect effect are reported alongside as a quick check.

eQTL mediators

For exposure → expression → AD triads, the X → M leg needs trans effects of X’s instruments on expression. Most expression resources in OpenGWAS (eQTLGen, GTEx-derived sets) are cis-only, so most X instruments will be absent from the mediator dataset. Rows with mediator_type = "eqtl" are therefore skipped (with the count in status) when fewer than k_min_x_in_mediator X instruments are present. Cis-only mediators with 1–3 SNPs will also generally fail the conditional-F gate. Those genes are better handled as a separate drug-target analysis (expression → AD plus colocalization, as in smoking/06_cis_drugtarget.qmd) than as formal mediation.

Assumptions

  • No X × M interaction (accepted, not tested). Product-of-coefficients and MVMR both assume it.
  • Standard IV assumptions per leg. These were checked for X → Y in the prior univariable analyses. X → M is checked above for the first time.
  • Rare-outcome approximation. The product of a linear X → M slope and a log-OR M → Y | X slope is read as a log-OR. This holds approximately because AD is rare.
  • Outcome scale. Bellenguez includes proxy cases, so its betas are not clinical log-ORs. Compare across outcomes on proportions and direction.
  • Sample overlap. Lean mass (UKB) and 2hGlu (MAGIC cohorts, no UKB) do not overlap, so conditional F uses gencov = 0. Lean mass, lifespan and Bellenguez all draw on UKB. Step 2’s robust-MR work found overlap immaterial for a comparable configuration, but it is not modelled here.
  • Covariate-adjusted GWAS. See the warning under Configuration.
  • b_SH draws. These use a normal approximation to SlopeHunter’s bootstrap distribution until the replicates are saved (boot_rds).
