SlopeHunter supplementary figures

What the survival-collider correction does, and how much it takes to change the result

Author

Dave Bridges

Published

November 11, 2026

Two supplementary figures for the SlopeHunter correction of Bellenguez AD:

  1. Mechanism (panels A–D): the problem, how b is estimated, how the correction is applied, and what it does to the BMI → AD estimate.
  2. Sensitivity to b: each MR estimate as a function of b, with every independent estimate of b we have.

The roles here are the reverse of a disease-progression analysis. Survival is the selection event: AD is only observed in people who live long enough to be ascertained. AD is the outcome. So the correction shifts each variant’s AD association by its lifespan association:

\[\hat\beta_{AD,j}^{\,corr} = \hat\beta_{AD,j} - b\,\hat\beta_{life,j}\]

Variants with no effect on lifespan do not move. Lifespan is a Martingale residual, so positive betas mean shorter life. b is negative: among survivors, alleles that shorten life look protective for AD.

# Arrows trimmed by r0 / r1 (data units) at each end so they stop at the node labels.
edge <- function(from, to, r0 = 0.45, r1 = 0.5) {
  a <- nodes[nodes$id == from, ]; z <- nodes[nodes$id == to, ]
  d <- sqrt((z$x - a$x)^2 + (z$y - a$y)^2); ux <- (z$x - a$x) / d; uy <- (z$y - a$y) / d
  tibble(x = a$x + r0 * ux, y = a$y + r0 * uy, xend = z$x - r1 * ux, yend = z$y - r1 * uy)
}

Caption (draft). Figure S1. How the survival-collider correction works. (A) AD is only observed in people who survive to be ascertained, so every AD GWAS is selected on survival (S). Variants that change survival, directly or through adiposity, become associated with other causes of survival (U) among the survivors. Because U also affects AD, each variant acquires a spurious AD association proportional to its effect on survival. (B) Each point is an independent variant associated with parental lifespan (p < 10⁻³, 2,326 variants, APOE excluded), plotted by its effects on lifespan and on AD (Bellenguez 2022). SlopeHunter’s mixture model finds the cluster of variants whose AD associations come only from their effect on survival (dark grey). The slope of that cluster is the selection slope b̂ = -0.94 (-1.08 to -0.81) (bootstrap 95% CI, dotted lines). It is negative because, among survivors, alleles that shorten life look protective for AD. (C) The correction shifts each variant’s AD association by −b̂ × its lifespan association, so variants with no effect on survival do not move, and the survival-only cluster loses its slope. Panels B and C share axes. 14 points lie beyond the plotted range. (D) BMI instruments (classical set, BMI-raising allele) before (open circles) and after (filled) correction, coloured by their effect on lifespan. Lines are MRBEE estimates. The corrected interval includes the uncertainty in b̂. Instruments whose BMI-raising allele shortens life move up, which removes the apparent protective effect of BMI. With fixed weights, the corrected estimate is approximately the uncorrected one minus b̂ × the BMI → lifespan estimate from the same instruments. Cluster labels come from a SlopeHunter refit on the pipeline’s merge (b = -0.935); the applied b̂ comes from the same GWAS with a slightly different merge.

# Each MR estimate (classical instruments, Bellenguez) refitted on a grid of fixed b, by IVW-MRE
# (smooth: with fixed weights it is linear in b) and MRBEE (the main-text estimator; its pleiotropy
# screen adds or drops a variant at some b, which shows as steps). SEs are conditional on b
# (se_b = 0), so the ribbon is the uncertainty at that b alone.
exposures <- c(bmi_ukb = "BMI (per SD)", fatmass_ukb = "Fat mass (per SD)",
               ffm_ukb = "Fat-free mass (per SD)", leanmass_pei = "Appendicular lean mass (per SD)",
               t2d_xue = "Type 2 diabetes (per log-odds)", glu2h_chen = "2 h glucose (per mmol/L)")
grid_b <- seq(0, -1.5, by = -0.025)
pair_data <- function(e) {
  ad   <- inst |> filter(assoc_id == paste0(e, "__ad_bellenguez__raw")) |>
    select(SNP, ea = effect_allele, bx = beta_exposure, sx = se_exposure, by = beta_outcome, sy = se_outcome)
  life <- inst |> filter(assoc_id == paste0(e, "__lifespan__raw")) |>
    select(SNP, ea_l = effect_allele, bl = beta_outcome, sl = se_outcome)
  inner_join(ad, life, by = "SNP") |> filter(ea == ea_l)
}
mrbee_at <- function(d, b, r) {
  f <- suppressWarnings(MRBEE::MRBEE.IMRP.UV(by = d$by - b * d$bl, bx = d$bx,
                                             byse = sqrt(d$sy^2 + b^2 * d$sl^2), bxse = d$sx,
                                             Rxy = matrix(c(1, r, r, 1), 2)))
  tibble(b_sel = b, estimator = "MRBEE", est = as.numeric(f$theta)[1], se = sqrt(as.numeric(f$vartheta)[1]))
}
ivw_at <- function(d, b) {
  y <- d$by - b * d$bl; s <- sqrt(d$sy^2 + b^2 * d$sl^2)
  sm <- summary(lm(y ~ 0 + d$bx, weights = 1 / s^2))
  tibble(b_sel = b, estimator = "IVW-MRE", est = sm$coefficients[1, 1],
         se = sm$coefficients[1, 2] / sm$sigma * sqrt(max(1, sm$sigma^2)))
}

Caption (draft). Figure S2. Sensitivity of the MR estimates to the selection slope. (A) Estimates of b from the same AD and lifespan GWAS, with 95% CIs. The SlopeHunter mixture model is shown three ways: as applied, refitted, and refitted without variants associated with BMI or fat mass (p < 10⁻⁵; b = -0.94). The last shows that selection acting through adiposity does not drive b. The other estimates use strong lifespan instruments, excluding those at AD loci, so they do not depend on SlopeHunter’s mixture model. One is the AD-on-lifespan regression (IVW, weighted median), the other the lifespan coefficient of an MVMR with BMI. For reference, SlopeHunter on permuted, signal-free data gives the median and range in grey. (B) Each exposure’s estimate on Bellenguez AD, refitted at fixed values of b by IVW-MRE (solid, with 95% CI conditional on that b) and MRBEE (dashed). b = 0 is the uncorrected analysis. The vertical line and grey band mark the estimated b and its bootstrap CI. With fixed weights the IVW estimate is linear in b; MRBEE’s steps are its pleiotropy screen adding or dropping a variant.

  • Not sensitive to b: lean mass and fat-free mass stay protective, and 2 h glucose stays positive, at every b from 0 to −1.5. Type 2 diabetes is null throughout.
  • Sensitive to b: the BMI estimate is no longer significant once b ≤ -0.425, and it crosses zero at b = -0.875 (IVW-MRE). Fat mass is no longer significant from b = -0.975. So “no protective effect of BMI” needs only about half the estimated slope, while flipping its sign needs almost all of it.
